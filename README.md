# Red Half Lab

A Liverpool supporter's independent football data projects: REDS reports, Match Pulse research and dated project updates.

- Project pages: https://liv-ynwa.github.io/redhalflabdata/
- Main website: https://redhalflab.com/
- X: https://x.com/REDSdataml4
- Match Pulse research snapshots: https://github.com/liv-ynwa/Matchpulse

## Publishing

This repository contains the standalone English static project site. GitHub Pages publishes from the main branch root. No build or runtime dependencies are required.

Future updates are prepared twice weekly and reviewed before publication. Earlier issues retain their dates and evidence scope. The site does not publish private forecasts, model files, source datasets or credentials.

## Assets

Project graphics are available as PNG and SVG in assets/cards. The condensed fallback font is Bebas Neue by Dharma Type; its SIL Open Font License is included in assets/fonts/OFL.txt.

Red Half Lab is independent of Liverpool Football Club. Models and reports are still developing.
